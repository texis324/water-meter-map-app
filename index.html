❓ 操作ガイド

📍 ピン追加モード / 🔒 閲覧モード
タップで切替。追加モード中は地図タップでピンを置ける。閲覧モードではピン追加されない
🔢 並替え
ピンをタップした順に番号を振り直す。開始番号も指定可能。同じ場所の建物は🏢ワンタップでまとめ取り
🔒保留: 並替え中にピンを右クリック（スマホは長押し）すると琥珀色になり、その番号のまま動かなくなる。「この1軒だけ今の順番で置いておきたい」時に使う。もう一度右クリックで解除。
⌨ PCショートカット: Space = 🔒閲覧⇄📍ピン追加 切替（他モード中は無効） / R = 🔁範囲反転（始点→終点をタップでその区間を丸ごと逆順に・隣同士なら2本入替・Shift+終点タップで離れた2本だけ入替・自動終了） / L = ✏️ルート線/区切り線 開始（バナーで「区切り線（破線）」＋色を選べる。Enter=完了・Backspace=戻す・Esc=取消。線は右クリックで削除・タップで編集） / D = 🔗連結 開始/中止（前半の終点→後半の始点をタップ。間のピンは末尾へ回る） / N = 並替えモード開始 / 以下は並替え中のみ → Backspace または Z = 直前の取り込みを戻す（押しっぱなしで連続。まとめ取りは丸ごと戻る） / Enter = 完了 / Esc = 取消（確認あり）
👆 なぞり順
マウスドラッグで線を引き、触れたピンを線の順番で自動並べ替え
🔗 連結
2つのピンをタップして間をスキップ連結。例: 83→141に繋げると、84〜140は後方に移動
📦 グループ
投げ縄で囲んでグループ化。縮小すると1ピン表示。ダブルクリックで展開/縮小、右クリックで解除
🗑️ 範囲削除
投げ縄で囲んだピンを一括削除
🖐 まとめて移動
囲むかタップで複数ピンを選択→✥ハンドルをドラッグで相対位置を保ったまま一括移動。「移動を取消」で開始前に戻せる
↩ 戻す / ↪ 進む
直前の操作を取消し / やり直し
🔄 ルート表示
Google Directions APIで道路に沿ったルート線を表示
✏️ ルート線
タップでルートの点を打ち、自由に線を引く。完了後に右クリックで編集可能。濃さスライダーで調節
✏️ 編集 ▾ / ⚙️ その他 ▾
編集: 並替え・スタンプ等のモードをまとめたメニュー。その他: 書出し/読込み・参照ピン・チェック・表示設定
💾 保存について
操作のたびにブラウザへ自動保存（ログイン中は自動でクラウドにも同期）。手動保存は不要。JSONバックアップは⚙️その他→書出し
📋 一覧
右サイドにピンのリストを表示。検索・タップでピンにジャンプ
🖱️ マウス操作
左クリック: ピン削除（即時）
ダブルクリック: 同一座標ピン全消去 / グループ展開・縮小
右クリック: ピンの詳細編集（ラベル・メモ・色）
地図ダブルクリック: Googleストリートビューを開く
地図右クリック（スマホ長押し）: 📌指定番号のピンをそこへパッと移動（無ければ新規作成）。「12〜25」のように範囲指定すると番号帯を一気に召喚
ドラッグ: ピンの位置を移動
